# Player IPTV (Android TV)

Substitua todo o conteúdo do repositório por estes arquivos (apague a pasta `app` antiga antes).
O GitHub Actions compila sozinho; o APK sai em Actions > Artifacts > IPTVPlayer-APK.

A interface fica em `app/src/main/assets/index.html`.
Para já abrir com a sua lista, preencha `DEFAULT_LIST` no começo do script desse arquivo.
